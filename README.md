# Tien's Dual Wield

**In development, nothing works yet.** Fight with a weapon in each hand, built for multiplayer from the start.

Planned:

- **Swap hands**: a key swaps the items in your two hands.
- **Off-hand attacks**: with a one-handed weapon in each hand (melee or handgun), hold the off-hand key while attacking
  to swing the weapon in your left hand.
- **Attack with both hands**: with two one-handed melee weapons, a key swings both at once.
- **Two handguns**: every shot fires both guns. The off-hand gun never fires alone. Reloading always reloads the gun in
  your main hand; swap hands to reload the other one.

Keys are set in the game's Key Bindings, under **Dual Wield**. Each feature can be switched off in the sandbox options
(page **Tien's Dual Wield**).

Build 42 only. In multiplayer the server needs it in its mod list like any other mod.
